# 当前实现与后续修改方向

本文记录代码审视后的方向，不是已完成功能清单。

## 当前基础

已建立空间、成员、个人 Agent、空间助理和专项 Agent 的角色模型；支持任务整理分配、执行交付、讨论升级、人工确认、反馈沉淀团队标准和空间记忆。

本次页面调整突出任务负责人、执行者、当前进展、下一步、讨论及成员的个人 Agent。有限次数定时任务增加自动完成分支：记录数量符合预期且交付自检全部通过时自动结项；缺失、额外记录或自检失败进入人工确认。

## 优先修改

1. **任务之外的输入**：增加同步信息、请求帮助；空间助理识别影响、通知相关个人 Agent，必要时形成任务或讨论。目前讨论入口依附任务。
2. **个人 Agent 的持续参与**：订阅主人相关事项，判断变化影响，响应求助，汇总跨空间事项，并从主人纠正中形成可查看和修改的偏好。目前主要在讨论、预审和决策建议时触发。
3. **共享状态与变更传播**：记录依赖、受影响成员、变更来源和处理状态。共享上下文注入提示词不足以保证变化被相关执行者处理。
4. **分歧终止授权**：明确 Owner Agent 可决定的范围、必须本人判断的事项、决定依据、推翻和身份转移机制。不能仅依赖提示词判断权限。
5. **验收策略**：区分客观核验、人工确认与异常介入，替换按任务类型增加特例的方式。当前定时执行记录和自检仍由 Agent 回报，不等于对 dsh 执行状态的独立验证。
6. **人的控制**：支持指定负责人或执行者；实质改变范围、期限或责任时确认；任务合并和补充需求后通知执行者重新判断影响；提供补充、暂停和调整入口。
7. **界面组织**：突出需要本人处理的事、相关变化、空间正在推进的事、已形成的共识。活动应可追溯到具体事项，不用文案暗示尚未实现的主动能力。

## dsh 集成待核验

当前每轮工作创建新的 dsh 会话，由提示词注入空间上下文；每个 Agent 有独立运行目录与运行时。定时任务存活检查读取 dsh 本地存储。后续需核验会话连续性、事件接收、定时任务状态同步和真实执行证据，不能把 Agent 自报等同于独立验证。

## 建议先跑通的场景

成员同步变化 → 空间识别影响 → 相关个人 Agent 响应 → 调整任务或发起讨论 → 授权范围内解决，必要时找人 → 结果和依据进入共享状态。

## 本次验证情况

类型检查和前端生产构建通过。定时自动完成的四项针对性测试通过：完整记录、缺失记录、自检失败、额外记录。dsh 端到端测试未完成，全链路尚未验证。
