# 产品初衷与方向

本文根据产品讨论整理。它描述产品意图及后续方向，不代表所有能力已经实现。

## 初衷

Agent 已经能帮助个人提效，但个人提效不会自然转化为组织提效。个人经常受限于执行能力、时间与精力；组织还受限于信息同步、协作等待、分歧处理和结果验证。我们希望探索下一代 Agent 产品，帮助一群人持续把事情做成。

## 和个人桌面 agent 的关系

Agent 空间是个人桌面 agent 延伸到团队之后的形态。每个人在进空间之前，已经有一个观察工作、记住偏好、能替主人先行动的个人 agent。拾遗是这种个人侧产品的一种样子。它积累下来的工作方式、标准、过往决定，以及什么会通过、什么会打回，是它后来能代表主人的原因。

空间里发生的，是这些个人 agent 带着已经形成的理解走到一起：代表主人参加讨论和预审，与空间助理、专项 agent 协作，只在需要人做决定时把事情交回来。

这个可运行的演示把那段积累当作已经完成。手写的公开档案和判断手册，就是桌面 agent 已经学到的内容在这里的替身。学习过程不在这次演示里，也不是尚未补上的缺口。

## 看到的问题

- 上下文分散在个人、私人 Agent 会话和不同工具里，成员可能依据不同的信息工作。
- 同步进展、解释背景、请求帮助和确认取舍依赖人的在线与响应。
- 执行变快后，审核和决策可能成为新的瓶颈，产出增加也可能增加返工。
- 现有多 Agent 方案偏重执行分工，缺少共同上下文维护、责任协调与分歧处理。
- 人的岗位和流程受到带宽、精力及沟通成本约束，不能简单照搬成数字员工。

## 对未来的判断

个人 Agent 会成为持续存在、逐渐了解主人的工作伙伴，在日常工作中积累习惯、经验、判断依据和标准。组织协作会包含更多 Agent 之间的同步与协调，人不必亲自完成每一次沟通，但始终可以直接介入。

共享上下文是组织级 Agent 产品的基础。目标、任务、资料、产物、决策及原因归空间；个人判断手册、私有背景和偏好归个人。个人 Agent 在授权边界内带入判断，不意味着公开全部私人信息。

个人 Agent 的核心价值是理解并代表主人。通用与专项 Agent 提供可调度的执行能力。人的反馈可沉淀为个人偏好或团队标准，自主程度随能力与信任逐步提高。

## 产品目标

一个面向组织提效的多人、多 Agent 协作空间。人与各自的个人 Agent 在共享上下文中协作，由空间 Agent 协调推进，结合专业 Agent 的执行能力，完成从需求提出、信息同步、分歧处理到结果交付的全过程。

空间可以承载有明确目标的项目，也可以长期服务于一个团队。目标可选，不强制设置生命周期。产品定位文案不以 IM 群作对标；从已有协作工具导入成员和背景仅是降低启动成本的入口。

## 角色与原则

- 人：提出任务、补充信息、更新目标、直接沟通、确认交付和承担责任。
- 个人 Agent：代表主人，带入标准与立场，关注相关变化、同步进展、请求帮助、预审交付，并汇总跨空间事项。
- 空间 Agent：整理、修正和合并任务，按明确目标拆解工作，协调分工、组织讨论、维护共享上下文和团队标准。
- Owner 的个人 Agent：在授权范围内，以 Owner 名义承担分歧终止职责；权力随 Owner 身份转移，决定可追溯、可推翻。
- 通用与专项 Agent：承担实际执行并提交可核验结果。

任务既可以由人发起，也可以来自明确目标的拆解或外部事件。人可以指定执行者，也可以委托空间协调。空间和组织积累随空间留存，个人私有层随人走。

## 如何衡量价值

关注从意图到结果的周期、协作等待时间、每个结果消耗的人的注意力、返工情况和处理结果的可信度。不能仅以 Agent 的产出数量衡量组织提效。
